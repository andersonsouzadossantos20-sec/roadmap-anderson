# 🛡️ Minha Jornada em Cybersecurity

Repositório dedicado a documentar minha evolução na área de **Cibersegurança**, desde os primeiros estudos até o desenvolvimento de conhecimentos mais específicos em **Penetration Testing**.

---

## 📖 Sobre a Jornada

Aos **15 anos**, iniciei meus estudos em programação com **Python**. Em seguida, direcionei o aprendizado para o desenvolvimento web backend, trabalhando com **Flask, APIs, WebSockets, Linux e servidores**.

Durante o desenvolvimento de uma aplicação web do zero — do planejamento ao deploy — comecei a me preocupar com a segurança da aplicação e da infraestrutura. A partir dessa experiência, passei a estudar segurança web e a compreender melhor como vulnerabilidades funcionam e como podem ser exploradas em ambientes controlados.

Aos **16 anos**, decidi direcionar minha trajetória para **Cibersegurança**, aproveitando a base já construída em desenvolvimento web e iniciando uma formação mais estruturada em redes, sistemas operacionais e segurança ofensiva.

Meu primeiro passo formal foi estudar pela **Cisco Networking Academy**, onde construí uma base sólida em redes e passei a compreender melhor o funcionamento da infraestrutura por trás das aplicações.

Atualmente, continuo aprofundando meus conhecimentos em redes e avançando na trilha **Penetration Tester Job Role Path**, da **Hack The Box**, com foco no desenvolvimento das habilidades necessárias para atuar profissionalmente com **Penetration Testing** e, futuramente, buscar a certificação **HTB CPTS**.
