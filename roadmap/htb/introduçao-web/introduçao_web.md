Hoje dei início ao módulo **Introdução a Aplicações Web** na Hack The Box Academy.

Antes de partir para testes de segurança, é essencial entender como uma aplicação web funciona internamente. Foi justamente esse o foco dos estudos de hoje.

### Alguns conceitos estudados:

🔹 **Introdução às Aplicações Web**
→ Entender o que é uma aplicação web, como ela funciona e quais componentes fazem parte da sua arquitetura.

🔹 **Layout de uma Aplicação Web**
→ Como uma aplicação é organizada, desde a interface apresentada ao usuário até a comunicação com o servidor e o banco de dados.

🔹 **Front-end vs. Back-end**
→ Compreender a diferença entre as duas camadas:

* **Front-end:** tudo o que o usuário vê e interage no navegador (HTML, CSS e JavaScript).
* **Back-end:** responsável pela lógica da aplicação, processamento das requisições, autenticação e comunicação com o banco de dados.

Perceber como essas partes trabalham em conjunto ajuda a entender melhor o funcionamento de uma aplicação antes mesmo de pensar em encontrar vulnerabilidades.

Cada novo módulo reforça uma ideia importante: para identificar falhas em um sistema, primeiro é preciso entender como ele foi construído e como cada componente se comunica com os demais.
