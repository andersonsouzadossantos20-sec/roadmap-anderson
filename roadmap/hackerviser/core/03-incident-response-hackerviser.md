# 🧠 Explicação Técnica

**Incident Response (IR)** é o processo utilizado por uma organização para identificar, analisar, conter e responder a incidentes de segurança.

O objetivo é reduzir o impacto causado pelo incidente, controlar a ameaça, recuperar os sistemas afetados e utilizar as informações obtidas durante o incidente para melhorar a segurança da organização.

O **Incident Response Lifecycle** organiza esse processo em diferentes fases.
