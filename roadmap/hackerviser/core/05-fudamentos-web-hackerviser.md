# 🎯 Objetivo do Estudo

Compreender os fundamentos necessários para entender como a Web funciona e como clientes e servidores se comunicam através da Internet.

O estudo abordou a diferença entre Internet e Web, o modelo cliente-servidor, o funcionamento básico do DNS e o protocolo HTTP.

O objetivo principal foi construir uma base para compreender posteriormente conceitos como requisições HTTP, respostas, headers, cookies, autenticação, APIs e vulnerabilidades de aplicações Web.

# 🧠 Explicação Técnica

## 1. Internet e Web

A **Internet** é uma infraestrutura global formada pela interconexão de diversas redes.

Ela permite que dispositivos e sistemas diferentes se comuniquem utilizando diversos protocolos.

Exemplos de serviços que utilizam a Internet:

- Web
- E-mail
- SSH
- FTP
- DNS

A **World Wide Web (WWW)** é um serviço que funciona sobre a Internet.

A Web utiliza principalmente tecnologias como:

- HTTP/HTTPS
- URLs
- Navegadores
- Servidores Web
- HTML
- CSS
- JavaScript
