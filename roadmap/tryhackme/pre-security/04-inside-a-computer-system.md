## 📚 Resumo

Room introdutória sobre os componentes físicos de um computador, suas funções e a maneira como trabalham juntos para permitir que o sistema funcione. Também aborda o processo de inicialização do computador.

## 🧠 Aprendizados

- Identificar os principais componentes de um computador.
- Compreender a função de cada componente.
- Entender como as peças trabalham em conjunto.
- Conhecer as etapas básicas da inicialização de um computador.
- Compreender a importância do hardware para o funcionamento do sistema operacional.

## 💻 Comandos / Ferramentas

- **Ferramenta:** laboratório interativo de montagem e identificação dos componentes de um computador.
- **Finalidade:** reconhecer as peças e entender suas funções dentro do sistema.
- **Resultado:** atividade prática concluída na plataforma.

## 📝 Anotações

### Principais componentes

- **CPU:** executa instruções e processa operações.
- **RAM:** armazena temporariamente os dados e programas em uso.
- **Armazenamento (SSD/HDD):** guarda arquivos, programas e o sistema operacional.
- **Placa-mãe:** conecta os componentes e permite a comunicação entre eles.
- **Fonte de alimentação (PSU):** fornece energia elétrica aos componentes.
- **GPU:** processa gráficos e outras tarefas compatíveis.
- **Sistema de refrigeração:** ajuda a controlar a temperatura dos componentes.

### Inicialização do computador

1. O botão de energia inicia o processo.
2. O firmware UEFI/BIOS começa a execução.
3. O POST verifica componentes essenciais.
4. O sistema procura o dispositivo de inicialização.
5. O bootloader inicia o carregamento do sistema operacional na memória.
