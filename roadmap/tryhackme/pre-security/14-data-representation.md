## 📚 Resumo

Sala sobre as formas de representação numérica utilizadas pelos computadores. O conteúdo apresenta os sistemas decimal, binário, hexadecimal e octal, além dos conceitos de bits, bytes e representação de cores.

Esses conceitos ajudam a compreender como os computadores armazenam, processam e representam informações digitalmente.

## 🧠 Aprendizados

- Compreender os sistemas decimal, binário, hexadecimal e octal.
- Entender como os computadores representam valores utilizando bits.
- Diferenciar bit e byte.
- Conhecer a relação entre números binários e hexadecimais.
- Entender como valores numéricos podem representar cores.
- Reconhecer a importância da representação de dados na computação.

## 💻 Conceitos principais

| Conceito | Descrição |
|----------|-----------|
| Decimal | Sistema numérico de base 10 |
| Binário | Sistema numérico de base 2, utilizando 0 e 1 |

## 📝 Anotações

### Sistema binário

Os computadores utilizam bits, que podem assumir os valores 0 ou 1, para representar informações.

Exemplo:

- Binário: `1010`
- Decimal: `10`

### Sistema hexadecimal

O hexadecimal utiliza 16 símbolos: os números de 0 a 9 e as letras de A a F.

Ele facilita a leitura de valores binários, pois cada dígito hexadecimal corresponde a quatro bits.

Exemplo:

- Binário: `1111`
- Hexadecimal: `F`
- Decimal: `15`

### Bits, bytes e cores

Um byte possui 8 bits. Na representação RGB, cada componente de cor costuma utilizar um byte, permitindo valores de 0 a 255 para vermelho, verde e azul.

A combinação desses componentes permite representar milhões de cores.
