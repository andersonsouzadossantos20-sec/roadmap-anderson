## 📝 Anotações

### Interface gráfica do Windows

A interface gráfica permite interagir com o sistema operacional por meio de janelas, ícones, menus e outros elementos visuais.

Principais componentes:

- **Área de trabalho:** espaço principal para acessar arquivos, pastas e atalhos.
- **Barra de tarefas:** permite acessar aplicativos abertos e fixados, além de notificações e outros controles.
- **Menu Iniciar:** fornece acesso a aplicativos, configurações e opções de energia.
- **Pesquisa:** facilita a localização de arquivos, aplicativos e configurações.

### Gerenciamento de arquivos e pastas

O Explorador de Arquivos é a ferramenta utilizada para navegar pelo sistema de arquivos do Windows.

Com ele, é possível:

- Criar, copiar, mover e excluir arquivos e pastas.
- Organizar documentos.
- Navegar entre unidades e diretórios.
- Localizar arquivos armazenados no computador.

### Configurações do Windows e Painel de Controle

O Windows disponibiliza ferramentas para personalizar e administrar o sistema.

- **Configurações do Windows:** interface moderna para ajustar opções do sistema, dispositivos, rede, personalização e segurança.
- **Painel de Controle:** interface tradicional que ainda disponibiliza diversas opções administrativas.

### Gerenciamento de processos

O Gerenciador de Tarefas permite visualizar aplicativos e processos em execução, além de acompanhar o uso de recursos como CPU, memória RAM e disco.

Essa ferramenta ajuda a identificar programas que consomem muitos recursos e investigar problemas de desempenho.

### Atualizações do sistema

O Windows Update distribui atualizações do sistema operacional, incluindo correções de segurança, melhorias e correções de erros.

Manter o sistema atualizado é importante para reduzir a exposição a vulnerabilidades conhecidas.

### Segurança do Windows

O Windows possui ferramentas integradas para ajudar a proteger o computador contra ameaças.

- **Microsoft Defender:** oferece recursos de proteção contra malware e outras ameaças.
- **Firewall do Windows:** controla o tráfego de rede conforme as regras configuradas.
- **Windows Update:** ajuda a manter o sistema protegido por meio de atualizações.

Esses mecanismos trabalham em conjunto, mas não substituem boas práticas de segurança, como utilizar senhas fortes, limitar privilégios e evitar arquivos suspeitos.
