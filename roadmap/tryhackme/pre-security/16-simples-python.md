## 📚 Resumo

Nesta sala, tive uma introdução prática à linguagem de programação Python, aprendendo conceitos fundamentais para compreender como os programas funcionam.

O conteúdo abordou o uso de **variáveis**, estruturas condicionais (`if` e `else`) e estruturas de repetição (`while`). Esses conceitos permitem armazenar informações, tomar decisões com base em condições e repetir instruções durante a execução de um programa.

Python é uma linguagem útil na área de cibersegurança, podendo ser utilizada futuramente para automatizar tarefas, analisar dados e desenvolver scripts.

---

## 🧠 Aprendizados

- **Variáveis:** armazenam informações que podem ser utilizadas durante a execução de um programa.
- **Condicionais (`if` e `else`):** permitem executar diferentes instruções dependendo de uma condição.
- **Laços de repetição (`while`):** executam um bloco de código enquanto determinada condição for verdadeira.
- **Lógica de programação:** compreender como as instruções são executadas e como as condições influenciam o comportamento de um programa.
- **Automação:** entender como esses fundamentos podem ser aplicados futuramente na criação de scripts para tarefas de cibersegurança.

---

## 💻 Comandos / Ferramentas

**Exemplo de variável:**

```python
nome = "Aluno"
print(nome)
```

**Exemplo de condição:**

```python
numero = 10

if numero > 5:
    print("O número é maior que 5")
else:
    print("O número é menor ou igual a 5")
```

**Exemplo de repetição:**

```python
contador = 1

while contador <= 5:
    print(contador)
    contador += 1
```

---

## 📝 Anotações

- A função `print()` exibe informações na saída do programa.
- O operador `=` atribui um valor a uma variável.
- O operador `>` compara dois valores.
- A estrutura `if/else` permite tomar decisões.
- O laço `while` precisa de uma condição que possa se tornar falsa para evitar repetições infinitas.
- A indentação é importante em Python, pois define os blocos de código.
