## 📚 Resumo

Room introdutória que explica o modelo Cliente-Servidor, a base da comunicação na internet. Usa a analogia de pedir pizza para ilustrar como dispositivos se comunicam, solicitam serviços e recebem respostas. Cobre conceitos fundamentais como cliente, servidor, request/response, protocolo, porta, DNS e HTTP/HTTPS.

---

## 🧠 Aprendizados

- Compreender o modelo Cliente-Servidor
- Diferenciar cliente (quem inicia a comunicação) de servidor (quem responde)
- Entender o fluxo Request → Response
- Conhecer conceitos básicos: DNS, Porta, Protocolo, Rede e IP
- Identificar as partes de uma URL (scheme e host)

## 📝 Anotações

### Conceitos principais

| Conceito | Explicação simples |
|----------|--------------------|
| **Cliente** | Quem inicia a comunicação (ex: navegador) |
| **Servidor** | Quem recebe a solicitação e responde (ex: site) |
| **Request** | Pedido enviado pelo cliente |
| **Response** | Resposta enviada pelo servidor |
| **Protocolo** | Regras e linguagem da comunicação (ex: HTTP, HTTPS) |
| **Porta** | Identifica um serviço específico no servidor |
| **DNS** | Traduz nomes (ex: google.com) em endereços IP |
| **IP Address** | Endereço do servidor na rede |

### Analogia da Pizza (Task 2)

- **Cliente** → pessoa que faz o pedido  
- **Servidor** → pizzaria  
- **Request** → “quero uma pizza grande de pepperoni e um refrigerante”  
- **Response** → a pizza entregue  
- **Protocolo** → a forma padronizada de fazer o pedido  
- **Porta** → o “balcão” específico do serviço  
- **DNS** → o GPS que encontra o endereço da pizzaria  

### Web Communication (Task 3)

- **HTTP** = Hypertext Transfer Protocol (protocolo da web)
- **HTTPS** = versão segura (criptografada)
- Em uma URL como `https://www.iamlearning.thm/contact`:
  - **Scheme** = `https`
  - **Host** = `www.iamlearning.thm`
